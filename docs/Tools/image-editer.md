# 画像編集ツール

ブラウザ上で動作する画像を編集したりするツールです。  
ツール内で「保存」という文言がありますが、  
処理的には画像ファイルをダウンロードします。  
サーバー上に画像ファイルを保存するものではありません。


# できること
## トリミング
好きなサイズから1:1の正方形、16:9、9:16、4:3、3:2、3:1にトリミングできます。  
好きなようにトリミングしたら「トリミングを実行」をクリックしてください。  
トリミング結果が表示されるので、問題なさそうなら、ダウンロードボタンをクリックしてダウンロードしてください。

## リサイズ
画像をピクセル指定・パーセント指定・プリセットでリサイズできます。  
好きなように設定して「リサイズを実行」を押すとリサイズされます。  
あとは画像リストにある「保存」ボタン(複数あるなら「全てを一括ZIPでダウンロード」ボタン)でダウンロードできます。

## 回転・反転
画像を回転させたり反転させたりできます。  
回転時の余白も選択できます。  
好きに回転・反転させたあとは、ダウンロードを押すことでダウンロードできます。

## 文字入れ
読み込んだ画像に文字を入れることができます。  
画像サイズがでかいものは重くなると思います。扱いにはご注意ください。  
文字の位置は配置プリセットか、直接ドラックすることで場所を変更できます。  
フォントやフォントサイズ、文字色、不透明度、縁取り、ドロップシャドウ、背景ボックスも変更できます。  
「画像をダウンロード」で文字入れした画像をダウンロードできます。

## フォーマット変換
pngからjpgに変換などができます。  
変換はpng、jpg、webp、bmp、iconが選択できます。  
「一括変換を実行」をクリックして、変換をしてから、「保存」ボタンか一括ZIPダウンロードボタンでダウンロードできます。  

## Exif編集・削除
画像ファイルを選択することで、写真のGPS情報やカメラ情報、撮影日時などを編集・削除することができます。  
全て削除は左側の「すべてのExifを完全削除して保存」がてっとり早いと思います。  
GPS情報のみ削除なら「GPS位置情報のみ削除して保存」をどうぞ。  
好きに編集したい場合は、右側の「Exif情報を編集・追加」から好きに情報を入力してください。  
入力後「Exif情報を更新して保存」をクリックしてダウンロードできます。  

読み込んだExif情報も見れます。

## Gif作成
選択した画像でGifを作成できます。  
フレーム間隔などを設定し、「GIFアニメーションを作成」ボタンを押すと作成されます。  
下に「作成されたGIFアニメーション」でプレビューできますので、問題なければ、「GIFをダウンロード」でダウンロードしてください。  

## Gif分解
選択したGifをフレーム単位に分割します。  
分割後、個別に「保存」ボタンを押すか、「全フレームを一括ZIPダウンロード」でダウンロードできます。  
ファイル形式もPNG、JPG、Webpが選択できます。  

## フィルター・色調
選択した画像にフィルタや色調を調整できます。  
大きい画像は処理に時間がかかる、端末(ブラウザ)が重くなります。仕様です。  
プリセットからフィルタをかけることもできます。  
あとは「画像をダウンロード」をクリックしてダウンロードしてください。

# コードとホスト
コードはAntigravity Cliが書いて、CloudFlare Pagesでホストしています。  
最初に書いた通り、サーバ側に画像などの情報を保存しない仕組みです。
