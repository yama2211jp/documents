# 画像結合ツール

X(Twitter)で分割された画像ツイートを結合するツールです。  
ブラウザ上で動作するツールで、サーバー上にデータを保存しない安心仕様です。

# 使い方
## ツイート
[画像結合ツール](https://image-stitcher.yama2211.jp/)のツイートURL(またはツイートID)を入力して「画像を取得」ボタンをクリック  
あとはツールが結合してくれるので、「結合画像をダウンロード」をクリックするだけです。

結合する画像の順番を入れ替えたり、レイアウトを変えたりできます。

## 画像ファイルを選択
「画像ファイルを選択」から画像を選ぶことで、X(Twitter)以外の画像も結合できます。  
複数枚の画像を選択して、「2×2グリット結合」とかにすればいい感じに結合してくれます。

# コードとホスト
コードはAntigravity Cliが書いて、CloudFlare Pagesでホストしています。  
最初に書いた通り、サーバ側に画像などの情報を保存しない仕組みです。
