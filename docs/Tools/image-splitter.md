# 画像分割ツール

画像を2～4分割するツールです。  
X(Twitter)で最近よく見る画像ツイートみたいな感じにできます。

# 使い方
## ツイート
[画像分割ツール](https://splitter-image.yama2211.jp/)のツイートURL(またはツイートID)を入力して「画像を取得」ボタンをクリック  
分割数や縦分割か横分割かを選択して「全ピースを一括zipダウンロード」で分割画像をzipでダウンロードされます。

## 画像ファイルを選択
「画像ファイルを選択」から画像を選ぶことで、X(Twitter)以外の画像も分割できます。  
分割数や縦分割か横分割かを選択して「全ピースを一括zipダウンロード」で分割画像をzipでダウンロードされます。

# コードとホスト
コードはAntigravity Cliが書いて、CloudFlare Pagesでホストしています。  
最初に書いた通り、サーバ側に画像などの情報を保存しない仕組みです。
