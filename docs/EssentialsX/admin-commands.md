# EssentialsX 管理者向けコマンド解説

[← コマンド総合一覧へ戻る](README.md) | [← 一般向けコマンド](general-commands.md) | [← モデレーター向けコマンド](moderator-commands.md)

---

このページでは、サーバーの最高権限を持つ**管理者（サーバーオーナー / OP / Administrator）**が使用する EssentialsX の高度なコマンドを日本語で詳しく解説します。

サーバー全体のパフォーマンス確認、プラグイン設定の再読み込み、ワールドの環境改変、プレイヤーへのチート能力（無敵・飛行など）の付与、経済残高の強制編集など、サーバーの根幹を管理するための機能が網羅されています。

> **警告**: 管理者向けコマンドはサーバーのワールドデータや経済バランスに恒久的な影響を与えるものが含まれます。実行前に必ず引数や対象を確認してください。

## 1. サーバー管理・保守・リロード系

### `/essentials reload`
- **構文**: `/essentials reload`
- **エイリアス**: `/ess reload`
- **権限ノード**: `essentials.essentials`
- **効果・解説**:
  EssentialsX 本体の `config.yml` や各アドオンの設定ファイルを再読み込みします。
  サーバーを再起動することなく、チャット設定やスポーン設定、キット設定などの変更を即座に反映させることができます。

### `/essentials dump`
- **構文**: `/essentials dump`
- **エイリアス**: `/ess dump`
- **権限ノード**: `essentials.essentials`
- **効果・解説**:
  サーバー環境、Javaバージョン、導入プラグイン一覧、主要設定のダンプ情報を生成し、共有用リンク（Pastebin / Bytebin）を出力します。公式Discord等でサポートを受ける際に必須となる情報です。

### `/essentials debug`
- **構文**: `/essentials debug`
- **エイリアス**: `/ess debug`
- **権限ノード**: `essentials.essentials`
- **効果・解説**:
  EssentialsX の詳細デバッグログ出力をオン/オフします。コマンド実行時の詳細な権限チェック挙動などをコンソールに出力して不具合を特定できます。

### `/gc` / `/lag` / `/mem`
- **構文**: `/gc`
- **エイリアス**: `/lag`, `/mem`, `/memory`
- **権限ノード**: `essentials.gc`
- **効果・解説**:
  サーバーの健康状態（ヘルスチェック）をリアルタイム表示します。
  - **TPS（Ticks Per Second）**: 理想値は 20.0。負荷が高くなると低下します。
  - **最大/割り当て/空きメモリ（RAM）**: JVMのヒープ使用状況。
  - **ワールド情報**: 各ワールドの読み込み済みチャンク数、エンティティ（Mob/アイテム）数、タイルエンティティ数。

### `/broadcast` / `/bc`
- **構文**: `/broadcast <メッセージ>`
- **エイリアス**: `/bc`, `/bcast`, `/shout`
- **権限ノード**: `essentials.broadcast`
- **効果・解説**:
  サーバー全体に太字やプレフィックス付きで公式告知メッセージ（全体アナウンス）を一斉送信します。定期連絡やメンテナンス予告に利用します。カラーコード（`&a`, `&c` 等）が使用可能です。
- **使用例**:
  - `/broadcast &e[お知らせ] &f10分後にサーバーの定期再起動を実施します。`

### `/backup`
- **構文**: `/backup`
- **エイリアス**: なし
- **権限ノード**: `essentials.backup`
- **効果・解説**:
  `config.yml` 内で指定された外部バックアップスクリプト（バッチファイルやシェルスクリプト）を手動トリガーで即座に実行します。

## 2. プレイヤー能力改変・チート・代理実行系

### `/god`
- **構文**: `/god [プレイヤー名] [on|off]`
- **エイリアス**: `/tgm`
- **権限ノード**: `essentials.god`, `essentials.god.others`
- **効果・解説**:
  ゴッドモード（完全無敵）を切り替えます。
  落下ダメージ、敵の攻撃、炎、窒息、空腹ゲージの減少など、奈落への落下以外のあらゆる被ダメージを無効化します。引数にプレイヤー名を指定すれば他人に付与・剥奪できます。

### `/fly`
- **構文**: `/fly [プレイヤー名] [on|off]`
- **エイリアス**: なし
- **権限ノード**: `essentials.fly`, `essentials.fly.others`
- **効果・解説**:
  サバイバルモードのままでも、クリエイティブモードのようにスペースキー2回押しで空中を自由に飛行できるようにします。高所建築やパトロール時に重宝します。

### `/heal`
- **構文**: `/heal [プレイヤー名]`
- **エイリアス**: なし
- **権限ノード**: `essentials.heal`, `essentials.heal.others`
- **効果・解説**:
  対象プレイヤーの体力を最大値まで回復し、満腹度を満タンにし、身体の炎や毒などの有害なステータス効果をすべて解除します。

### `/feed`
- **構文**: `/feed [プレイヤー名]`
- **エイリアス**: `/eat`
- **権限ノード**: `essentials.feed`, `essentials.feed.others`
- **効果・解説**:
  対象プレイヤーの満腹度ゲージ（空腹度）および隠し満腹度（Saturation）を一瞬で全快にします。

### `/extinguish` / `/ext`
- **構文**: `/extinguish [プレイヤー名]`
- **エイリアス**: `/ext`
- **権限ノード**: `essentials.ext`
- **効果・解説**:
  対象プレイヤーの身体についている火を即座に消火します。

### `/speed`
- **構文**: `/speed [walk|fly] <1〜10>` または `/speed <1〜10> [プレイヤー名]`
- **エイリアス**: なし
- **権限ノード**: `essentials.speed`, `essentials.speed.others`
- **効果・解説**:
  歩行速度（walk）または飛行速度（fly）の倍率を `1`（標準）から `10`（超高速）の範囲で変更します。
- **使用例**:
  - `/speed fly 3`（飛行速度を3倍にアップ）
  - `/speed walk 1`（歩行速度を標準にリセット）

### `/sudo`
- **構文**: `/sudo <プレイヤー名> <コマンド | 発言内容>`
- **エイリアス**: なし
- **権限ノード**: `essentials.sudo`, `essentials.sudo.exempt`
- **効果・解説**:
  指定したプレイヤーに成り代わり、そのプレイヤーの手でコマンドを実行させたり、チャットを発言させます（代理実行）。
  権限設定の動作テストや、チャット入力が分からない初心者の誘導に使用されます。
  ※先頭に `/` を付けるとコマンド実行、付けないと通常チャットになります。
- **使用例**:
  - `/sudo Steve /spawn`（Steveさんに強制的に `/spawn` を打たせる）
  - `/sudo Steve よろしくお願いします`（Steveさんにチャットを発言させる）

### `/kill`
- **構文**: `/kill <プレイヤー名>`
- **エイリアス**: なし
- **権限ノード**: `essentials.kill`
- **効果・解説**:
  対象プレイヤーを即座に死亡（即死）させます。

### `/killall`
- **構文**: `/killall [Mobタイプ] [ワールド名 | 半径]`
- **エイリアス**: `/butcher`
- **権限ノード**: `essentials.killall`
- **効果・解説**:
  サーバー内のモンスター、動物、または地面に落ちているドロップアイテムを一括消去します。
  モンスターの大量増殖（トラップタワー事故など）による急激なサーバーラグを解消する際の緊急停止措置として利用されます。
- **使用例**:
  - `/killall monsters`（全ワールドの敵対Mobを消去）
  - `/killall drops`（地面に散乱したドロップアイテムを消去）

### `/clearinventory` / `/ci`
- **構文**: `/clearinventory [プレイヤー名] [アイテム名] [個数]`
- **エイリアス**: `/ci`, `/clean`
- **権限ノード**: `essentials.clearinventory`, `essentials.clearinventory.others`
- **効果・解説**:
  対象プレイヤーのインベントリ内の持ち物を完全に消去（空っぽに）します。アイテム名と個数を指定した場合は、該当する特定アイテムだけを差し引くことも可能です。

## 3. アイテム生成・装備・どこでもGUI系

### `/give`
- **構文**: `/give <プレイヤー名> <アイテムID> [個数] [エンチャント/NBT]`
- **エイリアス**: なし
- **権限ノード**: `essentials.give`
- **効果・解説**:
  指定したプレイヤーにアイテムを直接付与します。オフラインプレイヤーには付与できません。

### `/item` / `/i`
- **構文**: `/item <アイテムID> [個数]`
- **エイリアス**: `/i`
- **権限ノード**: `essentials.item`
- **効果・解説**:
  コマンドを実行した自分自身のインベントリにアイテムを取り出します。クリエイティブインベントリを開く手間を省くことができます。

### `/more`
- **構文**: `/more`
- **エイリアス**: なし
- **権限ノード**: `essentials.more`
- **効果・解説**:
  現在手に持っているアイテムの個数を、そのアイテムの最大スタック数（通常64個）まで一瞬で補充・増殖させます。

### `/repair` / `/fix`
- **構文**: `/repair <hand | all>`
- **エイリアス**: `/fix`
- **権限ノード**: `essentials.repair`, `essentials.repair.all`, `essentials.repair.enchanted`
- **効果・解説**:
  ダメージを受けた武器・ツール・防具の耐久値を全回復させます。
  - `hand`: 手に持っているアイテム1つを修理
  - `all`: インベントリ内の全装備・ツールを一括修理

### `/enchant`
- **構文**: `/enchant <エンチャント名> [レベル]`
- **エイリアス**: なし
- **権限ノード**: `essentials.enchant`
- **効果・解説**:
  手に持っているアイテムに指定したエンチャントを直接付与します。
  設定（`unsafe-enchantments: true`）が有効な場合、通常のゲーム内限界（例: 鋭さ V）を超えるレベル（鋭さ X や ダメージ軽減 100 など）のいわゆる「神ツール」を作成できます。

### `/skull`
- **構文**: `/skull [プレイヤー名]`
- **エイリアス**: `/head`
- **権限ノード**: `essentials.skull`
- **効果・解説**:
  指定したプレイヤーのスキンテクスチャが反映された「プレイヤーの頭」ブロックを入手します。建築の装飾や記念品としてよく使われます。

### `/hat`
- **構文**: `/hat`
- **エイリアス**: `/headgear`
- **権限ノード**: `essentials.hat`
- **効果・解説**:
  手に持っているブロックやアイテム（ガラスブロック、バナー、花など）を、頭装備（ヘルメット枠）に装着します。個性的な見た目にカスタマイズできます。

### どこでもGUI（ポータブルユーティリティ）
ブロックを物理的に設置することなく、コマンド一発で各種ユーティリティの操作画面（GUI）をどこでも開くことができます。
- **`/workbench`**（`/wb`, `/craft`）: クラフト作業台を開く (`essentials.workbench`)
- **`/anvil`**: 金床画面を開く (`essentials.anvil`)
- **`/smithingtable`**: 鍛冶台画面を開く (`essentials.smithingtable`)
- **`/grindstone`**: 砥石画面を開く (`essentials.grindstone`)
- **`/cartographytable`**: 製図台画面を開く (`essentials.cartographytable`)
- **`/loom`**: 機織り機画面を開く (`essentials.loom`)
- **`/stonecutter`**: 石切台画面を開く (`essentials.stonecutter`)

### `/spawner`
- **構文**: `/spawner <Mob名>`
- **エイリアス**: なし
- **権限ノード**: `essentials.spawner`
- **効果・解説**:
  視線を合わせているモンスタースポナーブロックを、指定したMobの種類（`zombie`, `skeleton`, `blaze` など）のスポナーへ変化させます。

## 4. 環境・時間・天候・ワールド操作系

### `/time`
- **構文**: `/time <set | add> <day | night | 数値(0〜24000)>`
- **エイリアス**: なし
- **権限ノード**: `essentials.time`, `essentials.time.set`
- **効果・解説**:
  ワールド全体の時計（時刻）を変更します。
  - `/time set day`: 朝（1000 tick）に設定
  - `/time set night`: 夜（13000 tick）に設定

### `/weather`
- **構文**: `/weather <sun | rain | storm> [継続秒数]`
- **エイリアス**: なし
- **権限ノード**: `essentials.weather`
- **効果・解説**:
  ワールド全体の天候を晴れ（sun）、雨（rain）、雷雨（storm）に変更します。

### `/ptime` (Player Time)
- **構文**: `/ptime <day | night | ticks | reset> [プレイヤー名]`
- **エイリアス**: なし
- **権限ノード**: `essentials.ptime`, `essentials.ptime.others`
- **効果・解説**:
  ワールド全体の時刻は変更せず、**指定したプレイヤーの画面上だけ**の時刻を固定・偽装します。建築作業で常に昼間にしたい場合などに最適です。`reset` でサーバー本体の時刻と同期し直します。

### `/pweather` (Player Weather)
- **構文**: `/pweather <sun | storm | reset> [プレイヤー名]`
- **エイリアス**: なし
- **権限ノード**: `essentials.pweather`
- **効果・解説**:
  対象プレイヤーのクライアント側だけの天候を偽装します。雷雨の音がうるさい建築現場で自分だけ快晴にしたい時に便利です。

### `/break`
- **構文**: `/break`
- **エイリアス**: なし
- **権限ノード**: `essentials.break`
- **効果・解説**:
  現在視線を合わせているブロック（岩盤であっても）を一撃で強制破壊・消去します。

## 5. 経済（エコノミー）・経験値操作系

### `/eco`
- **構文**: `/eco <give | take | set | reset> <プレイヤー名 | **> <金額>`
- **エイリアス**: `/economy`
- **権限ノード**: `essentials.eco`, `essentials.eco.loan`
- **効果・解説**:
  サーバー経済システム上の残高を直接操作します。
  - `give`: 指定金額を付与
  - `take`: 指定金額を没収・減額
  - `set`: 指定金額を残高として強制上書き
  - `reset`: アカウント開設時の初期残高にリセット
  ※プレイヤー名に `**` を指定するとサーバー全員が対象になります。
- **使用例**:
  - `/eco give Steve 10000`（Steveさんに10,000ドル付与）
  - `/eco set Alex 0`（Alexさんの所持金をゼロにする）

### `/exp`
- **構文**: `/exp <give | set | show> <プレイヤー名> <数値[L]>`
- **エイリアス**: `/xp`
- **権限ノード**: `essentials.exp`, `essentials.exp.give`, `essentials.exp.set`
- **効果・解説**:
  プレイヤーの経験値ポイント（数値のみ）またはレベル（末尾に `L` を付与）を操作・付与します。
- **使用例**:
  - `/exp give Steve 30L`（Steveさんにレベル30分の経験値を付与）
  - `/exp set Alex 0`（Alexさんの経験値を0にリセット）

## 6. ワープ・監獄・自動化ツール設定系

### `/setwarp` / `/delwarp`
- **構文**: 
  - `/setwarp <ワープ名>`（現在地をワープ地点として登録）
  - `/delwarp <ワープ名>`（ワープ地点を削除）
- **エイリアス**: なし
- **権限ノード**: `essentials.setwarp`, `essentials.delwarp`
- **効果・解説**:
  一般プレイヤーが `/warp <ワープ名>` で移動できる公共ワープ地点を作成または削除します。

### `/setjail` / `/deljail`
- **構文**: 
  - `/setjail <監獄名>`（現在地を監獄セルとして登録）
  - `/deljail <監獄名>`（監獄セルを削除）
- **エイリアス**: なし
- **権限ノード**: `essentials.setjail`, `essentials.deljail`
- **効果・解説**:
  荒らしや違反者を隔離するための監獄ポイントを定義または削除します。

### `/powertool` / `/pt`
- **構文**: `/powertool [コマンド]`
- **エイリアス**: `/pt`
- **権限ノード**: `essentials.powertool`
- **効果・解説**:
  現在手に持っているアイテム（木の棒や羽根など）に任意のコマンドをバインド（紐付け）します。
  左クリックまたは右クリックするだけで、コマンドをチャットに打つことなく瞬時に発動させることができます。
  コマンドを空にして実行すると割り当てが解除されます。
- **使用例**:
  - `/powertool lightning`（木の棒を持った状態で実行 → 木の棒でブロックを殴ると落雷が発生）
  - `/powertool jump`（羽をクリックすると瞬時にそこへジャンプ移動）

### `/ptoggle`
- **構文**: `/ptoggle`
- **エイリアス**: なし
- **権限ノード**: `essentials.ptoggle`
- **効果・解説**:
  自分自身のパワーツール機能の有効/無効をグローバルに切り替えます。
