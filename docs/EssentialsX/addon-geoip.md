# EssentialsX GeoIP アドオン解説

[← コマンド総合一覧へ戻る](README.md) | [アドオン一覧](README.md#4-公式アドオン解説ページ一覧)

---

**EssentialsX GeoIP** は、サーバーに接続してきたプレイヤーの IP アドレスから、接続元の「国名（国コード）」や「地域」を自動判別し、各種情報表示コマンドやログインメッセージに統合する公式アドオンです。

海外からのアクセス監視、荒らし行為を行ったプレイヤーの接続地域調査、多言語対応サーバーでのプレイヤー属性の把握などに活用されます。

## 1. 機能概要とメリット

- **接続国の自動判定**: プレイヤーがログインした際、MaxMind 社の IP ロケーションデータベースを参照して瞬時に国を判定。
- **スタッフ調査コマンドの強化**: `/whois` や `/seen` に接続元国名（例: `Japan [JP]`）が自動追加。
- **不正アクセス・複垢対策**: 国内向けサーバーにおいて、不自然な海外IPからの連続ログインをスタッフが早期発見可能。

---

## 2. 影響を受けるコマンド

GeoIP 自体に入力実行する独立したコマンドはありませんが、EssentialsX の既存の情報確認コマンドの出力結果が自動的に拡張されます。

### `/whois <プレイヤー名>`
- **効果の拡張**:
  オンラインプレイヤーの調査画面に `Location: Japan (JP)` のように接続元情報が表示されます。
  モデレーターが不審なプレイヤーを調査する際の重要な判断材料となります。

### `/seen <プレイヤー名>`
- **効果の拡張**:
  オフラインプレイヤーの最終ログアウト履歴を確認した際、最後にログインしていた接続国が表示されます。

## 3. ログイン通知メッセージの設定

`plugins/Essentials/config.yml` 内で、プレイヤー参加時の国名表示を有効化できます。

```yaml
# スタッフ向けにログイン元の国を表示するか
show-player-join-location: true
```

設定が有効な場合、スタッフの画面に以下のようなメッセージが表示されます:
```text
Steve (192.0.2.1) joined from Japan [JP]
```

---

## 4. データベース（MaxMind GeoLite2）の仕様

EssentialsX GeoIP は、IP 判定のために **MaxMind GeoLite2** データベースを使用します。

- 初回起動時に最新のデータベースファイル（`.mmdb`）が自動的にダウンロードされます。
- MaxMind 社のライセンス要件により、必要に応じて `plugins/Essentials/config.yml` で MaxMind の無料アカウントライセンスキーを設定できます。
