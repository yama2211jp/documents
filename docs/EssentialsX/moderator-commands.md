# EssentialsX モデレーター・運営向けコマンド解説

[← コマンド総合一覧へ戻る](README.md) | [← 一般向けコマンド](general-commands.md) | [管理者向けコマンド →](admin-commands.md)

---

このページでは、サーバーの風紀維持、プレイヤー間のトラブル仲裁、チャット監視、不正行為・迷惑行為の取り締まりを担当する**モデレーター（運営スタッフ / Moderator / Helper / Staff）向け**のコマンドを詳しく日本語で解説します。

モデレーター向けコマンドは、一般プレイヤーには使用できない強力な権限を持ち、相手の承諾なしに移動させたり、発言や行動を制限・調査することができます。

> **記号の表記ルール**
> - `<必須引数>`: 必ず入力する必要がある項目です。
> - `[任意引数]`: 省略可能な項目です。
> - `[時間]`: `10m`（10分）、`2h`（2時間）、`7d`（7日）などの時間指定が可能です。

## 1. 処罰・行動制限系（Kick / Ban / Mute / Jail）

### `/kick`
- **構文**: `/kick <プレイヤー名> [理由]`
- **エイリアス**: なし
- **権限ノード**: `essentials.kick`, `essentials.kick.exempt`（キック免除権限）
- **効果・解説**:
  指定したプレイヤーをサーバーから強制切断（追い出し）させます。
  一時的な警告や、接続不調・放置しているプレイヤーを退場させたい時に使用します。BANではないため、プレイヤーはすぐに再接続することが可能です。
- **使用例**:
  - `/kick BadPlayer チャット連投はおやめください`

### `/kickall`
- **構文**: `/kickall [理由]`
- **エイリアス**: なし
- **権限ノード**: `essentials.kickall`
- **効果・解説**:
  自分（および免除権限持ち）を除く、サーバー内にいる全プレイヤーを一斉に強制切断します。
  緊急メンテナンスやサーバー再起動直前の退避に使用されます。

---

### `/mute`
- **構文**: `/mute <プレイヤー名> [時間]`
- **エイリアス**: なし
- **権限ノード**: `essentials.mute`, `essentials.mute.exempt`
- **効果・解説**:
  指定したプレイヤーのチャット発言およびプライベートメッセージ（`/msg`、`/mail` 等）を禁止します。
  時間を指定しない場合は**無期限ミュート**になります。もう一度同じコマンドを実行すると手動解除されます。
- **使用例**:
  - `/mute TrollUser`（無期限ミュート）

### `/tempmute`
- **構文**: `/tempmute <プレイヤー名> <時間> [理由]`
- **エイリアス**: なし
- **権限ノード**: `essentials.tempmute`
- **効果・解説**:
  指定した時間だけ一時的にチャットを禁止します。時間が経過すると自動的に解除されるため、日常的な軽微な違反（暴言、連投、宣伝など）の冷却期間として多用されます。
- **使用例**:
  - `/tempmute Spammer 30m チャットスパム行為のため`（30分間ミュート）
  - `/tempmute Player1 1d 不適切な発言`（1日間ミュート）

### `/unmute`
- **構文**: `/unmute <プレイヤー名>`
- **エイリアス**: なし
- **権限ノード**: `essentials.mute`
- **効果・解説**:
  ミュート状態にあるプレイヤーのミュートを即座に解除し、再び通常通り発言できるようにします。

---

### `/ban`
- **構文**: `/ban <プレイヤー名> [理由]`
- **エイリアス**: なし
- **権限ノード**: `essentials.ban`, `essentials.ban.exempt`
- **効果・解説**:
  指定したプレイヤーのアカウント（UUID）をサーバーから**無期限アクセス禁止（追放）**にします。
  サーバーの規約違反、チート使用、悪質な破壊行為（Griefing）など重大な事案に対して執行されます。
- **使用例**:
  - `/ban Cheater123 不正クライアント(X-Ray/Fly)使用確認`

### `/tempban`
- **構文**: `/tempban <プレイヤー名> <時間> [理由]`
- **エイリアス**: なし
- **権限ノード**: `essentials.tempban`
- **効果・解説**:
  指定した期間だけアクセスを禁止します。期間満了後は自動的に接続可能になります。
  反省期間を設ける際や、段階的なペナルティ運用（例: 初回1日、2回目7日、3回目永久）に最適です。
- **使用例**:
  - `/tempban BadActor 7d 他人の建築物を無断で改造したため`

### `/unban`
- **構文**: `/unban <プレイヤー名>`
- **エイリアス**: `/pardon`
- **権限ノード**: `essentials.unban`
- **効果・解説**:
  BANされたプレイヤーのアカウント処分を解除し、再度サーバーへログインできるようにします。

### `/banip`
- **構文**: `/banip <プレイヤー名 | IPアドレス> [理由]`
- **エイリアス**: なし
- **権限ノード**: `essentials.banip`
- **効果・解説**:
  指定したプレイヤーの接続元IPアドレス、または指定したIPアドレスを丸ごと接続拒否リストに追加します。
  サブアカウント（複垢）を作成して繰り返し荒らしに来る悪質ユーザーへの対抗措置として使用します。
  ※同一ネットワーク（学校や家庭内LANなど）の無関係なプレイヤーも巻き込まれる可能性があるため慎重に実行してください。

### `/unbanip`
- **構文**: `/unbanip <IPアドレス>`
- **エイリアス**: `/pardonip`
- **権限ノード**: `essentials.unbanip`
- **効果・解説**:
  IP-BANリストから指定IPアドレスを削除し、制限を解除します。

---

### `/jail`
- **構文**: `/jail <プレイヤー名> <監獄名> [時間]`
- **エイリアス**: なし
- **権限ノード**: `essentials.jail`, `essentials.jail.exempt`
- **効果・解説**:
  指定したプレイヤーをあらかじめ設定された「監獄（Jail）」エリアへ強制送致（投獄）します。
  投獄されたプレイヤーは、監獄外へのテレポート、ブロックの破壊・設置、コマンドの実行が原則禁止され、隔離されます。
  時間を指定すると、刑期満了時に自動で出所（元の場所またはスポーンへ復帰）します。
- **使用例**:
  - `/jail BadGuy cell1 15m`（cell1という監獄に15分間投獄）

### `/togglejail`
- **構文**: `/togglejail <プレイヤー名> [監獄名] [時間]`
- **エイリアス**: なし
- **権限ノード**: `essentials.togglejail`
- **効果・解説**:
  すでに投獄されているプレイヤーを釈放するか、通常プレイヤーを投獄状態にするかをワンライナーで切り替えます。

### `/jails`
- **構文**: `/jails`
- **エイリアス**: なし
- **権限ノード**: `essentials.jails`
- **効果・解説**:
  サーバー内に登録されている監獄名の一覧を表示します。

## 2. 調査・監視・インベントリ検査系

### `/seen`
- **構文**: `/seen <プレイヤー名>`
- **エイリアス**: なし
- **権限ノード**: `essentials.seen`, `essentials.seen.banreason`, `essentials.seen.ip`
- **効果・解説**:
  対象プレイヤーのログイン履歴やステータスを確認します。
  - **オフラインの場合**: 最終ログイン日時、オフライン経過時間、最後にログアウトした座標、BANされているか（BAN理由）
  - **オンラインの場合**: ログインしてからの経過時間、現在の接続IPアドレス
  トラブル調査やアカウントの同一性確認に極めて有用です。

### `/whois`
- **構文**: `/whois <プレイヤー名>`
- **エイリアス**: なし
- **権限ノード**: `essentials.whois`
- **効果・解説**:
  対象プレイヤーのリアルタイム詳細情報を一覧表示します。
  - 本名 / 表示名（Nickname）
  - 現在のHP（体力）、満腹度、残り酸素
  - ゲームモード、飛行モード状態、ゴッドモード状態
  - AFK（離席）フラグ、ミュート・投獄ステータス
  - 現在の所持金（Vault残高）
  - 接続IPアドレスおよび国籍（GeoIPアドオン導入時）

### `/invsee`
- **構文**: `/invsee <プレイヤー名>`
- **エイリアス**: なし
- **権限ノード**: `essentials.invsee`, `essentials.invsee.modify`（編集権限）
- **効果・解説**:
  オンライン中のプレイヤーの**インベントリ（持ち物・防具・オフハンド）をチェストGUIとして画面に開いて覗き見**します。
  不正に入手した禁止アイテム（岩盤、不正なエンチャント武器、大量の鉱石など）を所持していないか調査できます。
  `modify` 権限があれば、そのGUIからアイテムを直接没収したり差し替えたりすることも可能です。

### `/enderchest` / `/ec`
- **構文**: `/enderchest <プレイヤー名>`
- **エイリアス**: `/ec`
- **権限ノード**: `essentials.enderchest`, `essentials.enderchest.modify`
- **効果・解説**:
  対象プレイヤーの**エンダーチェスト（個人の四次元チェスト）**をGUIで開きます。
  隠し持っているアイテムや貴重品の不正所持を調査する際に使用します。

### `/socialspy`
- **構文**: `/socialspy [on|off]`
- **エイリアス**: `/spy`
- **権限ノード**: `essentials.socialspy`
- **効果・解説**:
  プライベートチャット監視モードを切り替えます。
  有効にすると、サーバー内の他プレイヤー同士がやり取りしている `/msg`（個人チャット）、`/mail`、`/helpop` などの内容がスタッフの画面にリアルタイムで傍受表示されます。
  暴言やいじめの裏取引、外部サイトへの誘導などの監視に役立ちます。

### `/vanish` / `/v`
- **構文**: `/vanish [on|off]`
- **エイリアス**: `/v`
- **権限ノード**: `essentials.vanish`, `essentials.vanish.see`（Vanishを見破る権限）
- **効果・解説**:
  自分の姿を完全に不可視（完全透明）にします。
  ポーションの透明化とは異なり、防具・手持ちアイテム・パーティクルも一切見えず、Tabリスト（プレイヤー一覧）からも名前が消去されます。
  怪しい動きをしているプレイヤーに気付かれることなく背後から密着監視（パトロール）する際に必須の機能です。

## 3. 移動・誘導・スタッフテレポート系

### `/tp`
- **構文**: `/tp <対象プレイヤー名>` または `/tp <プレイヤーA> <プレイヤーB>`
- **エイリアス**: なし
- **権限ノード**: `essentials.tp`, `essentials.tp.others`
- **効果・解説**:
  相手の許可を待たずに、即座に対象プレイヤーの場所へ瞬間移動します。
  第2引数に別のプレイヤーを指定した場合は、プレイヤーAをプレイヤーBの場所へ強制移動させます。

### `/tphere`
- **構文**: `/tphere <対象プレイヤー名>`
- **エイリアス**: `/s`
- **権限ノード**: `essentials.tphere`
- **効果・解説**:
  対象プレイヤーを、自分の足元へ強制的にテレポート（呼び出し）させます。
  注意・事情聴取を行いたい時や、迷子になったプレイヤーを助ける時に使用します。

### `/tpall`
- **構文**: `/tpall [ワールド名]`
- **エイリアス**: なし
- **権限ノード**: `essentials.tpall`
- **効果・解説**:
  サーバー内にいる全員（または特定ワールドの全員）を一斉に自分の元へテレポートさせます。
  全体イベントの開始時などに使用しますが、プレイヤーの作業を中断させるため慎重なアナウンスが必要です。

### `/tpo` / `/tpohere`
- **構文**: `/tpo <プレイヤー名>` / `/tpohere <プレイヤー名>`
- **エイリアス**: なし
- **権限ノード**: `essentials.teleport.hidden`, `essentials.tp.override`
- **効果・解説**:
  対象が `/tpatoggle` 等でテレポート受信拒否を設定していても、それを無視（Override）して強制的にテレポートまたは呼び出しを実行します。

### `/jump` / `/j`
- **構文**: `/jump`
- **エイリアス**: `/j`
- **権限ノード**: `essentials.jump`
- **効果・解説**:
  現在視線（クロスヘア）を合わせている遠くのブロックの上面へ、一瞬でテレポートします。
  高台の移動や長距離のショートカットに非常に便利です。

### `/top`
- **構文**: `/top`
- **エイリアス**: なし
- **権限ノード**: `essentials.top`
- **効果・解説**:
  現在のX, Z座標を維持したまま、頭上にある最も高い安全なブロック（地表や屋上）へ垂直ワープします。
  洞窟探索中に一瞬で地上へ戻りたい時などに使用します。

## 4. 運用上のベストプラクティス・注意点

1. **処罰ログの記録と理由の明記**:
   `/ban` や `/tempban`、`/kick` を実行する際は、必ず後ろに明確な理由（例: `荒らし行為(X:120 Y:64 Z:-300)`）を記載してください。他のモデレーターが `/seen` を見た際に処罰の正当性を確認できます。
2. **`/vanish` 中の行動**:
   Vanish状態であってもチェストを開けると音やアニメーションでバレる場合があります。設定（`config.yml` の silent chest 等）を確認し、怪しまれない調査を徹底しましょう。
3. **権限濫用の禁止**:
   `/invsee` で私利私欲のために他人のアイテムを持ち出したり、無断でテレポートを繰り返して通常プレイを妨害することはサーバー運営の信用失墜に直結します。モデレーター権限は明確な規約違反の対応時にのみ使用してください。
