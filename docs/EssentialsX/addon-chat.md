# EssentialsX Chat アドオン解説

[← コマンド総合一覧へ戻る](README.md) | [アドオン一覧](README.md#4-公式アドオン解説ページ一覧)

---

**EssentialsX Chat** は、Minecraftサーバーのチャット表示を美しくカスタマイズし、役職プレフィックス（Prefix）、名前の色、発言範囲などを細かく制御できる公式チャット管理アドオンです。

LuckPerms などの権限管理プラグインおよび Vault と連動することで、「[管理者] Steve: こんにちは」のようなグループ別の肩書表示や、近くにいる人にだけ聞こえる近接チャット（ローカルチャット）環境を簡単に構築できます。

## 1. 機能概要と役割

- **役職（Prefix / Suffix）の反映**: LuckPerms 等で設定した称号やグループタグを自動でチャット欄に挿入。
- **カラー＆装飾チャット**: カラーコード（`&a`、`&c` 等）やRGBカラー（`&#RRGGBB`）に対応。
- **URLリンクの自動ハイパーリンク化**: チャットに打ち込まれたURLをクリック可能にする。
- **チャット範囲制限**: サーバー全体に聞こえるグローバルチャットと、一定ブロック以内の人にだけ聞こえるローカルチャットの分離。

---

## 2. チャット関連コマンドと記号

EssentialsX Chat を導入すると、通常の会話や以下の記号が特別な効果を発揮します。

### シャウト発言（`!`）
- **構文**: `!<メッセージ>`
- **権限ノード**: `essentials.chat.shout`
- **効果・解説**:
  ローカルチャット（近接会話モード）が有効なサーバーにおいて、メッセージの先頭に `!` を付けて発言することで、距離制限を無視して**サーバー全体の全員へ大声で叫ぶ（Shout）**ことができます。
- **発言例**: `!みなさんこんにちは！中央広場へ集まってください！`

### 質問発言（`?`）
- **構文**: `?<メッセージ>`
- **権限ノード**: `essentials.chat.question`
- **効果・解説**:
  質問専用のプレフィックスを付けて発言します。設定により色が変わったり、スタッフに強調表示されます。

## 3. チャットフォーマットの設定（config.yml）

`plugins/Essentials/config.yml` 内の `chat` セクションで全体のフォーマットを定義します。

### 基本設定例
```yaml
chat:
  # 近接チャットの半径（0にするとサーバー全体に届く標準チャット）
  radius: 0

  # 全グループ共通の標準フォーマット
  # {DISPLAYNAME}: プレイヤー名（PrefixやNickname込み）
  # {MESSAGE}: 発言本文
  # {WORLDNAME}: 所属ワールド名
  format: '<{DISPLAYNAME}> {MESSAGE}'

  # グループ別のカスタムフォーマット（Vault + LuckPerms 連携時）
  group-formats:
    default: '&7[{GROUP}] &f{DISPLAYNAME}&7: &f{MESSAGE}'
    vip: '&6[{GROUP}] &e{DISPLAYNAME}&f: &a{MESSAGE}'
    admin: '&c[管理者] &4{DISPLAYNAME}&f: &c{MESSAGE}'
```

### 利用可能なプレースホルダー
- `{DISPLAYNAME}`: プレイヤーの表示名（役職Prefix・Suffix・カラー反映）
- `{NAME}`: プレイヤーの本来のMinecraft ID
- `{GROUP}`: 所属しているプライマリグループ名
- `{MESSAGE}`: プレイヤーが送信したチャット本文
- `{WORLDNAME}`: プレイヤーが現在いるワールド名
- `{SHORTWORLDNAME}`: ワールド名の頭文字1文字

## 4. 近接チャット（ローカルチャット）機能

ロールプレイ（RP）サーバーやサバイバル生活サーバーでは、`chat.radius` を設定することで現実的な会話距離を再現できます。

```yaml
chat:
  # 半径100ブロック以内のプレイヤーにだけチャットが届く
  radius: 100
  local-format: '&7[Local] &f{DISPLAYNAME}&7: {MESSAGE}'
  shout-format: '&6[Shout] &e{DISPLAYNAME}&f: {MESSAGE}'
```

- 半径内に誰もいない場合は、「誰もあなたの声を聞いていません」という通知が表示されます。
- スタッフは `essentials.chat.spy` 権限を持っていれば、距離に関係なく全ローカルチャットを監視できます。

## 5. 権限ノード一覧

| 権限ノード | デフォルト | 説明 |
| :--- | :--- | :--- |
| `essentials.chat.color` | OPのみ | チャットでカラーコード（`&0`〜`&f`）を使用可能にする |
| `essentials.chat.format` | OPのみ | 太字（`&l`）や斜体（`&o`）などの文字装飾を使用可能にする |
| `essentials.chat.magic` | OPのみ | 難読化文字（`&k`）を使用可能にする |
| `essentials.chat.url` | 全員 (true) | 入力したURLをクリック可能なリンクにする |
| `essentials.chat.shout` | 全員 (true) | `!` から始まる全体シャウト発言を許可する |
| `essentials.chat.question`| 全員 (true) | `?` から始まる質問発言を許可する |
| `essentials.chat.spy` | OPのみ | 距離制限のあるローカルチャットをすべて傍受・監視する |
