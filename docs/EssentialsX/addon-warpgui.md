# EssentialsX WarpGUI アドオン解説

[← コマンド総合一覧へ戻る](README.md) | [アドオン一覧](README.md#4-公式アドオン解説ページ一覧)

---

**EssentialsX WarpGUI** は、EssentialsX のワープ機能（`/warp`）をチェスト型のグラフィカルインターフェース（GUI）に置き換え、プレイヤーがアイテムアイコンをクリックするだけで直感的に目的地へテレポートできるようにするアドオンです。

チャット欄に表示されるテキストリストとは異なり、各ワープ地点ごとに「ダイヤモンドの剣」「本」「ベッド」などの自由なアイコンや、魅力的な説明文（Lore）を設定できます。

## 1. 機能概要とメリット

- **クリックで即テレポート**: ワープ名を正確にキーボードで入力する必要がなく、初心者やスマホ（Bedrock統合版）からの接続者にも親切です。
- **カスタムアイコンと説明文**: 各ワープ地点に好きなアイテムアイコン（ブロック、ツール等）やカラー付きの説明文を設定可能。
- **権限連動の表示制御**: プレイヤーがテレポート権限を持っていないワープ地点は、GUI上で自動的に「非表示」にするか「鍵付きアイコン（アクセス禁止）」として表示できます。

## 2. コマンド一覧と詳細解説

### `/warp`（GUIフック）
- **対象**: 全プレイヤー
- **構文**: `/warp [ワープ名]`
- **エイリアス**: なし
- **権限ノード**: `essentials.warp`
- **効果・解説**:
  引数なしで `/warp` を実行すると、通常のテキスト一覧の代わりに**ワープGUIメニューが画面にポップアップ表示**されます。
  アイテムをクリックすると、そのワープ地点へ即座に移動します。
  従来通り `/warp shop` のように直接ワープ名を指定してテレポートすることも可能です。

---

### `/warpgui`
- **対象**: 全プレイヤー
- **構文**: `/warpgui`
- **エイリアス**: なし
- **権限ノード**: `essentials.warp`
- **効果・解説**:
  明示的にワープ選択GUIを開きます。他のプラグインと `/warp` コマンドが競合している場合にも確実にGUIを呼び出せます。

---

### `/warpcfg`
- **対象**: 管理者（OP）
- **構文**: `/warpcfg [reload | edit]`
- **エイリアス**: なし
- **権限ノード**: `warpcfg.cfg`
- **効果・解説**:
  WarpGUI の設定を管理します。
  - `/warpcfg reload`: 設定ファイル（アイコン、表示名、説明文など）をサーバー再起動なしで再読み込みします。
  - ゲーム内GUIエディタ対応版の場合、アイコンの配置変更メニューを開きます。

## 3. GUIカスタマイズと設定例

設定ファイル（`plugins/EssentialsWarpGUI/config.yml`）でGUIの外観を自由に変更できます。

```yaml
# GUIのタイトル（カラーコード対応）
gui-title: "&1&lワールド・施設ワープ一覧"

# GUIの行数 (1〜6)
gui-rows: 4

# 各ワープポイントの設定
warps:
  spawn:
    slot: 10
    item: COMPASS
    name: "&a&l中央ロビー・初期広場"
    lore:
      - "&7サーバーのメイン拠点です。"
      - "&eクリックしてテレポート！"
  shop:
    slot: 12
    item: EMERALD
    name: "&6&l商店街・マーケット"
    lore:
      - "&7アイテムの売買やショップが並んでいます。"
      - "&eクリックしてテレポート！"
  pvp:
    slot: 14
    item: DIAMOND_SWORD
    name: "&c&lPvPアリーナ"
    lore:
      - "&7対人戦が可能な危険エリアです！"
      - "&4※装備ロストに注意してください"
  mining:
    slot: 16
    item: IRON_PICKAXE
    name: "&b&l資源採掘ワールド"
    lore:
      - "&7整地・ブランチマイニング専用ワールド。"
```

## 4. 権限ノード一覧

| 権限ノード | デフォルト | 説明 |
| :--- | :--- | :--- |
| `essentials.warp` | 全員 (true) | `/warp` コマンドおよびGUIを開く |
| `essentials.warps.<ワープ名>` | 設定依存 | 特定のワープ地点へのアクセス権（持っていない場合はGUIで非表示または移動不可） |
| `essentials.warps.*` | OPのみ | サーバー内のすべてのワープ地点へのアクセスを許可 |
| `warpcfg.cfg` | OPのみ | `/warpcfg` 管理コマンドの実行権限 |
